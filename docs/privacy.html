プライバシーポリシー

simple Java Property Editor（以下、本アプリ）のプライバシーポリシーです。

収集する情報

本アプリは、個人を特定できる情報を収集しません。アカウント登録もなく、入力内容やファイルの内容を開発者のサーバーへ送信しません。

端末内に残るもの

開いた .properties ファイルと、上書き保存の直前に作る .properties.bk は、利用している PC の中だけに残ります。本アプリがこれらを外部へ送ることはありません。

Microsoft Store

ストアからの入手や更新では、Microsoft が独自に情報を扱う場合があります。その扱いは Microsoft のプライバシーに関する声明に従います。
